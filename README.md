This component provides middlewares to authenticate API requests using PHP
League OAuth2.

## Requirements

- PHP 8.3 or higher

## Installation

You can install the LMC API OAuth2 Authentication library with composer:

```sh
$ php composer.phar require lm-commons/lmc-api-auth-oauth2
```
